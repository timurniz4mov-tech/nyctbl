# Песчаный апокалипсис — Minecraft 1.20.1 Forge

Мод добавляет медленно распространяющуюся пустыню, которая превращает природную поверхность мира в песок. Распространение проверяется раз в секунду. Чем дольше существует мир, тем быстрее растёт заражённая область; днём распространение идёт в два раза быстрее, чем ночью.

## Что добавлено

- При первом входе в обычный мир рядом с начальным местом игрока (на расстоянии **10–100 блоков**) появляется светящееся **Сердце пустыни**.
- От очага песок постепенно распространяется по природной поверхности: трава, земля, камень, гравий, глина и некоторые другие природные блоки превращаются в обычный песок.
- Скорость увеличивается с каждым новым игровым днём (до установленного предела) и дополнительно удваивается в дневное время.
- Мод не превращает дерево, постройки игрока, сундуки и другие созданные игроком блоки. Новые участки заражаются по мере исследования и загрузки местности; мод не загружает чанки принудительно.
- У игрока есть шкала жажды. Жажда быстрее убывает днём, во время бега и в жарких биомах. При очень низкой жажде появляется замедление, а при нуле игрок получает урон.
- **Фляга с водой** восстанавливает 35 единиц жажды. После использования возвращается пустая стеклянная бутылка.
- Очаг, заражённые участки и жажда сохраняются в мире и у игрока после выхода из игры.
- Добавлены русские и английские названия, текстуры, рецепт фляги и отдельная вкладка творческого режима.

## Как получить `.jar` через GitHub.com

1. Скачай ZIP с исходным проектом и распакуй его на компьютере.
2. Открой свой репозиторий на GitHub.com. Для этого мода лучше создать отдельный репозиторий, например `sand-apocalypse`.
3. Нажми **Add file → Upload files** и загрузи **содержимое папки `SandApocalypse`**, а не сам ZIP. В корне репозитория должны быть видны `build.gradle`, `settings.gradle`, `gradle.properties`, папка `src` и папка `.github`.
4. Нажми **Commit changes**. Файл `.github/workflows/build.yml` автоматически запустит сборку.
5. Открой вкладку **Actions**, выбери последний запуск **Build Sand Apocalypse**, затем внизу страницы открой **Artifacts** и скачай `sandapocalypse-minecraft-1.20.1-forge`.
6. В скачанном архиве будет файл `.jar`. Положи его в папку `mods` установленного Minecraft Forge **1.20.1**.

Сборка использует Java 17 и Gradle 8.8. Gradle устанавливается GitHub Actions автоматически — wrapper-файлы вручную добавлять не нужно.

## Проверка в игре

Создай новый мир в режиме выживания. При первом входе появится сообщение о начале апокалипсиса. Осмотрись в радиусе до 100 блоков — ищи светящееся Сердце пустыни. Шкала жажды появится слева над индикаторами здоровья и брони. Флягу можно создать на верстаке из железных самородков, стеклянных панелей и стеклянной бутылки.
